# 발표자료와 코드의 해석 범위

- 발표자료의 원본 2페이지는 팀원 소개·역할 분담 페이지여서 공개 복사본에서 제외했습니다. 표지의 팀원 이름·MEMBERS 표기도 제거했습니다. 나머지 페이지의 분석 내용은 보존했습니다. 삭제 뒤 PDF의 실제 페이지 위치와 슬라이드 하단의 원래 번호는 다릅니다.
- 원본 23페이지에는 1,001개 Vocab, 27페이지에는 정상·이상 기업의 매핑 키워드 수가 등장합니다. 현재 `legacy/category_vocab.py`의 사전 항목 367개 및 7개 규칙 카테고리와 동일한 집계라고 단정하지 않습니다.
- 원본 11페이지의 보고서 수, 16~18페이지의 기업 수는 서로 집계 단위가 다르거나 중간 상태일 수 있습니다. 코드·원자료 전수 재현으로 단일 데이터 규모를 확정하지 않았습니다.
- 원본 29~39페이지는 규칙 기반 근거 구성·LLM·DB 설계 흐름, 41~57페이지는 당시 웹의 예시입니다. 현재 화면·API·로컬 저장 방식과 차이가 있습니다.
- 발표자료에 은행 교육용 데이터 결합 구상이 등장하지만 현재 공개 웹은 개별 기업의 은행 거래를 연결해 검증하지 않습니다. 회사 식별자가 없는 자료의 업종 분포 비교를 기업 단위의 직접 비교로 소개하지 않습니다.
- 발표자료는 사용자가 공개를 허용한 범위의 복사본입니다. 제3자 자료·기사·기업 예시의 권리를 새로 부여하지 않았습니다. 공개 저장소의 별도 라이선스는 임의 생성하지 않았습니다.

## 개인 기여 표기의 근거

개인 역할은 이번 정리 요청에서 사용자가 확인한 범위를 반영했습니다. 공식 PM이 아닌 전체 방향 총괄·기획·파이프라인 구축·정합성 검증·기술 전반 활용으로 표현했습니다. 팀이 구축한 사전과 팀 전체 결과를 개인 단독 산출물로 쓰지 않았습니다.

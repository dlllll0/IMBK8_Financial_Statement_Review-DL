# 검증 범위

## 정리본에서 실행한 검증

Python 3.12.14의 기존 개발 환경에서 공개용 폴더의 테스트 26개를 실행했습니다. 테스트는 합성 입력·모의 API 응답을 사용하며 실제 고객 자료나 외부 API 키를 필요로 하지 않습니다.

- 변화 분류, 겹침 없는 문자열 위치, 한글·이모지 위치
- 잘못된 PDF/JSON·작업 ID 거부, OCR 비활성 상태
- 검토 기록 저장·재조회, 최종 보고서의 상태·메모·이스케이프
- 출처 ID·원문 인용·숫자 검증과 검증 실패 시 미저장
- 단순한 API 스키마 사용, 인용문에서 출처 목록 구성
- 다른 문단·계정 연결, 은행 데이터 부재 표시
- 전기 0·음수·단위 미확인·원 환산과 계정별 검토 질문
- Windows 상태 파일의 일시적 공유 잠금 재시도

JavaScript 구문도 별도로 검사했습니다. 발표자료는 59페이지 중 원본 2페이지를 제거한 58페이지 PDF이며, 표지의 팀원 표기를 제거하고 메타데이터를 비웠습니다. 수정 대상 외 57페이지의 추출 텍스트가 원본과 동일함을 비교했고 표지·이웃 페이지를 렌더링해 확인했습니다. 원본 PDF 해시는 변경되지 않았습니다.

## 실제 실행에서 확인한 것

- 사용자 환경에서 Gemini API의 짧은 요청 성공
- 실제 업로드 보고서의 OCR·분석 결과 화면 출력: 사용자 확인
- 합성 문장으로 실제 Gemini 설명 생성과 출처 검증 성공: 사용자 진단 출력 확인
- 저장된 로컬 결과에 추가 비교·페이지 연결 적용
- 합성 데모에서 카드 상세창과 기록 모아보기·필터 확인

## 아직 검증하지 않은 것

- 새 PC·새 가상환경에서 전체 의존성을 설치한 독립 재현
- 모든 문서 형식과 스캔 PDF에 대한 전수 정확도
- 마지막 금액 가이드·연결 규칙까지 반영한 전체 외부 API 재실행의 독립 검증
- 실제 기업의 부정 탐지 성능, RM 업무 시간 절감률, 이익·손실 개선
- 다중 사용자 동시 실행, 인증·접근 권한과 운영 배포

발표자료의 예시는 기존 프로젝트 기록입니다. 발표자료의 수치를 이 정리본의 새 실험 결과로 전환하지 않았습니다.
